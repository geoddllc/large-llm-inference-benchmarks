# mistralai/mistral-nemo

## Model Overview
Mistral Nemo is a 12B parameter model developed by Mistral AI in collaboration with NVIDIA.

## Supported Hardware Platforms
- Nvidia RTX 6000 Blackwell
- Nvidia L40s
- Nvidia H100
- Nvidia RTX 6000

## Available Inference Stacks
- Deploypad Geodd
- VLLM Vanilla
